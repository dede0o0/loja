# Fios de PDO

Cópia editável da página de referência fornecida, em HTML e CSS responsivos.

Abra `index.html` diretamente no navegador ou publique a pasta raiz em uma hospedagem estática. Imagens e fontes estão incorporadas ao arquivo. As imagens ampliadas ainda abrem seus endereços originais no Framer.

- Preço preservado: R$ 59,99.
- Checkout: https://sun.eduzz.com/39VKR4NBWR
- FAQ nativo, sem JavaScript.
- Layout adaptável para celular e computador.
- Sem pixel ou analytics instalado.

Para alterar textos, preço, links e aparência, edite `index.html`.

Os campos entre colchetes no rodapé são os mesmos da referência. Complete identificação do vendedor, contato, termos e política de privacidade antes de divulgar.
